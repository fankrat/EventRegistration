# Модуль регистрации участников мероприятий

Курсовой проект по специальности «Информационные системы и программирование».
Тема: Проектирование и разработка модуля регистрации участников мероприятий.

## Описание проекта
Модуль представляет собой веб-приложение для управления мероприятиями и учёта регистрации участников. 
Программа позволяет создавать мероприятия, добавлять участников, регистрировать их на мероприятия, 
отменять регистрацию и автоматически подсчитывать количество свободных мест.

## Используемые технологии
- Платформа: .NET 8 (ASP.NET Core MVC)
- Язык: C#
- База данных: SQLite (через Entity Framework Core)
- Тестирование: xUnit

## Архитектура проекта
- `Models` — сущности предметной области (Event, Participant, Registration).
- `Data` — контекст базы данных (AppDbContext).
- `Services` — бизнес-логика (RegistrationService: проверки на свободные места и дубли).
- `Controllers` — обработка HTTP-запросов.
- `Views` — пользовательский интерфейс.

## Инструкция запуска
1. Откройте терминал (PowerShell) в папке проекта.
2. Выполните команду: `dotnet run`
3. В консоли появится адрес, например: `http://localhost:5047`
4. Откройте этот адрес в браузере.
5. При первом запуске база данных `events.db` создастся автоматически вместе с тестовыми данными.

## Инструкция пользователя (основной сценарий)
1. **Добавление мероприятия:** Перейдите в раздел «Мероприятия» и нажмите «Добавить мероприятие». Укажите название, дату, место и количество мест.
2. **Добавление участника:** Перейдите в раздел «Участники» и нажмите «Добавить участника». Введите ФИО и контакты.
3. **Регистрация на мероприятие:** В списке мероприятий нажмите «Зарегистрировать», выберите участника из выпадающего списка и подтвердите действие.
4. **Проверка мест:** На странице «Подробнее» отображается список участников и автоматически рассчитанное количество свободных мест.
5. **Отмена регистрации:** На странице мероприятия нажмите «Отменить» рядом с участником. Статус изменится на «Отменена», а свободное место вернется.
