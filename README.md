\# Модуль регистрации участников мероприятий



Курсовой проект по специальности «Информационные системы и программирование».

Тема: Проектирование и разработка модуля регистрации участников мероприятий.



\## Этап 3: Первый проект ASP.NET Core



\### Как запустить проект

1\. Откройте терминал (PowerShell) в папке проекта.

2\. Выполните команду: `dotnet run`

3\. В консоли появится адрес, например: `http://localhost:5047`

4\. Откройте этот адрес в браузере.

5\. Перейдите на страницу со списком мероприятий: `http://localhost:5047/Events`



\### Используемые технологии

\- Платформа: .NET 8 (ASP.NET Core MVC)

\- Язык: C#

\- Хранение данных: учебные записи в памяти (List<Event>)



\### Учебные данные

На странице `/Events` отображаются 3 тестовых мероприятия:

\- Тестовое мероприятие (01.12.2026, Актовый зал, 5 мест)

\- Лекция по C# (10.12.2026, Аудитория 305, 20 мест)

\- Спортивный турнир (15.12.2026, Спортзал, 10 мест)
